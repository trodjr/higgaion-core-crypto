# Security Policy

## Supported Versions

Currently, only the latest `main` branch is proactively supported for security updates.

## Reporting a Vulnerability

We request that you report any security vulnerabilities by opening a private GitHub Security Advisory or securely emailing the maintainer at [security@higgaion.com](mailto:security@higgaion.com).
In accordance with coordinated vulnerability disclosure, we will review the submission within 30 days and aim to disclose the patch and details within 90 days.
